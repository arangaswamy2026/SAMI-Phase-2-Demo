# Voice & Style

## Tone
<!-- e.g., formal, conversational, technical, plain language -->
- Formal and professional
- Direct and concise — no filler words
- No contractions, no slang, no emojis (unless explicitly requested)

## Formatting Preferences
- Bullet points for lists of 3 or more items
- Short paragraphs — prefer bullets over prose for structured content
- Use examples to clarify complex concepts

## Writing Style
- First-person when drafting communications on my behalf
- Avoid verbose explanations unless asked
- If a verbose version is needed, suggest a follow-up prompt to expand

## Output Defaults
- Artifacts: standalone HTML or React (light background, dark text)
- Documents: .docx or .md depending on context
- Presentations: SonicWall-branded .pptx using SNWL theme

## Audience Awareness
- Executive stakeholders: high-level, outcome-focused
- Engineering: precise, spec-driven
- End users (basic expertise): plain language, no jargon
